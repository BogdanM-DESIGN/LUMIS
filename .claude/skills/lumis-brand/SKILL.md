# LUMIS brand
Read `CLAUDE.md`, `.agents/product-marketing.md`, and the current site before designing.

Preserve the approved LUMIS wordmark, the four-lamp opening, Bodoni headings and Manrope text unless the user requests a new direction. Extract exact colours and spacing from current CSS instead of inventing a replacement brand. Prefer natural Romanian with diacritics, short clear descriptions and specific benefits supported by evidence.

For a narrow refinement use the existing design. Choose Impeccable for a structured audit/polish, or frontend-design for a new composition; avoid running overlapping redesign workflows together. Use webapp-testing after UI changes.

For product visuals use current CAD/3D geometry or real product photos as the reference. Keep base, ring, dimensions and silhouette consistent across website, advertisements and configurator. Label generated imagery and renders as illustrative; don't describe them as photographs of a manufactured lamp. If generation changes geometry, reject that variation for a product listing.

For day/night pairs keep the same camera, framing, object position and room geometry. Review overlays and visible silhouette alignment; file dimensions alone do not prove alignment. Retain the existing registered room sequence unless replacing all states together.

Deliver the brief, editable source, export sizes, concise Romanian copy and evidence of a desktop/mobile check. Use image/video/ad-creative/canvas-design only as relevant. State if the actual generation tool is unavailable rather than delivering a prompt as though it were a generated asset.
